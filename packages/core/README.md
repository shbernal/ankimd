# @ankimd/core

Convert [Flashcard Markdown](https://github.com/shbernal/flashcard-md-spec)
decks to and from Anki packages.

The library takes a deck and a path. Reading files off disk, globbing, config
and templates live in [`@ankimd/cli`](https://www.npmjs.com/package/@ankimd/cli)
instead, so a library consumer pulls neither.

## Status

Pre-release. The conversion is not written yet.

## Install

```sh
pnpm add @ankimd/core
```
